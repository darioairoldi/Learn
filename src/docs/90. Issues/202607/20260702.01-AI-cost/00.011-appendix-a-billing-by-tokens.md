## 🎯 Scope

This is Appendix A of [How Azure AI billing works](00.010-how-azure-ai-billing-works.md). It lists representative <mark>per-token list prices as of July 2026</mark> for Global/US deployments. Prices vary by region, currency, and agreement, and they change often — always confirm on the linked pricing pages before you budget.

Most Foundry models bill <mark>per token</mark> — input plus output, with cached input discounted. Three sub-cases sit inside this pattern:

-   <mark>Models sold by Azure</mark> — Azure OpenAI plus selected models from Cohere, DeepSeek, Meta, Mistral AI, xAI, Black Forest Labs, Microsoft, and others. Billed on Microsoft's first-party token meters, one meter per model per resource.
-   <mark>Partner models via Marketplace</mark> — for example Anthropic Claude, billed as CCU (token-derived; see below).
-   <mark>The exception: managed compute</mark> — open-source and custom models on dedicated GPUs bill per GPU-hour, not per token (last section).

For the conceptual difference between Azure-sold and partner models, see [Models sold by Azure versus partner models](00.010-how-azure-ai-billing-works.md#models-sold-by-azure-versus-partner-models).

| o3 | $2.00 | $0.50 | $8.00 |
| o4-mini | $1.10 | $0.28 | $4.40 |

-   <mark>Batch</mark> deployments run the same tokens at roughly 50% off (for example GPT-4.1 batch ≈ $1 input / $4 output).
-   <mark>Embeddings</mark> are input-only and cheap: `text-embedding-3-small` ≈ $0.02, `ada-002` ≈ $0.10, `text-embedding-3-large` ≈ $0.13 per 1M tokens.
-   <mark>Cached input</mark> is far cheaper than fresh input, which is why cache-hit ratio is worth tracking.
-   Reading a bill: 1M input + 1M output tokens on GPT-4o ≈ $2.50 + $10.00 = **$12.50**.

Image and audio models use their own per-image or per-minute (and per-token) meters — see the pricing page for exact rates.

## 🤝 Anthropic Claude (billed as CCU)

Claude models don't use the Azure OpenAI token meters. As [partner models](00.010-how-azure-ai-billing-works.md#models-sold-by-azure-versus-partner-models) they bill through <mark>**Claude Consumption Units (CCU)**</mark> on Azure Marketplace: tokens are rated in USD at the per-model rates below, any discount is applied, then the total converts to CCU at a fixed <mark>$0.01 per CCU</mark> (<mark>100 CCU = $1.00</mark>). Because that conversion is 1:1 with dollars, the effective cost per 1M tokens equals these rates — they just appear as one CCU line on your Azure invoice.

| Model | Input | Cache read | Output |
|---|---|---|---|
| Claude Opus 4.5–4.8 | <mark>**$5.00**</mark> | <mark>**$0.50**</mark> | <mark>**$25.00**</mark> |
| Claude Sonnet 5 (intro, through Aug 31, 2026) | <mark>**$2.00**</mark> | <mark>**$0.20**</mark> | <mark>**$10.00**</mark> |
| Claude Sonnet 5 (from Sep 1, 2026) | <mark>**$3.00**</mark> | <mark>**$0.30**</mark> | <mark>**$15.00**</mark> |
| Claude Sonnet 4.6 | <mark>**$3.00**</mark> | <mark>**$0.30**</mark> | <mark>**$15.00**</mark> |
| Claude Sonnet 4.5 | <mark>**$3.00**</mark> | <mark>**$0.30**</mark> | <mark>**$15.00**</mark> |
| Claude Haiku 4.5 | <mark>**$1.00**</mark> | <mark>**$0.10**</mark> | <mark>**$5.00**</mark> |

-   <mark>**Cache read**</mark> (a cache hit) is 0.1× base input; cache *writes* cost more (1.25× for a 5-minute cache, 2× for a 1-hour cache).
-   <mark>**Batch**</mark> is 50% off (for example Opus ≈ $2.50 input / $12.50 output; Haiku ≈ $0.50 / $2.50).
-   The <mark>**US Data Zone**</mark> deployment applies a 1.1× multiplier across all token categories.
-   Foundry catalog availability varies by model and hosting option (Azure-hosted versus Anthropic-hosted) — check the catalog. Retired models (Opus 4/4.1, Sonnet 4, Haiku 3.5) are omitted.

## 🖥️ The exception: managed compute

Open-source, community, and custom models (Hugging Face, NVIDIA NIM, some Meta and Mistral models, industry models, Databricks, custom weights) deploy on <mark>managed compute</mark> — dedicated GPUs billed <mark>hourly per accelerator</mark>, not per token. Representative rates: Managed A100 80G ≈ **$4/hour**, H100 ≈ **$8/hour**, MI300 ≈ **$8/hour**. Cost is driven by GPU hours and utilization, so idle capacity is the waste to watch.
