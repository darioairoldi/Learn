## 🎯 Scope

This is Appendix B of [How Azure AI billing works](00.010-how-azure-ai-billing-works.md). It lists representative <mark>PTU list prices as of July 2026</mark> for Global/US deployments. Prices vary by region, currency, and agreement, and they change often — always confirm on the linked pricing pages.

Provisioned throughput bills <mark>flat hourly capacity, independent of tokens</mark>. For how token throughput maps to a PTU count (the Input TPM per PTU sizing formula and worked example), see [Relating token throughput to PTUs](00.010-how-azure-ai-billing-works.md#relating-token-throughput-to-ptus).

## 🔒 PTU prices

Per PTU — model-independent:

| Billing mode | Rate | Effective $/PTU/month |
|---|---|---|
| Hourly (Global) | $1.00 /PTU/hour | <mark>**~$730**</mark> (if run 24×7) |
| Hourly (Data Zone) | $1.10 /PTU/hour | <mark>**~$803**</mark> |
| Hourly (Regional) | $2.00 /PTU/hour | <mark>**~$1,460**</mark> |
| 1-month reservation (Global) | $260 /PTU/month | <mark>**$260**</mark> |
| 1-year reservation (Global) | $2,652 /PTU/year | <mark>**~$221**</mark> |

## 💡 Notes and break-even

-   The PTU *price* is model-independent; the *throughput* per PTU varies by model (see [Relating token throughput to PTUs](00.010-how-azure-ai-billing-works.md#relating-token-throughput-to-ptus)).
-   Minimum deployment: 15 PTU (Global/Data Zone), 25–50 PTU (Regional).
-   Reservations cut the effective rate sharply — a 1-year reservation is roughly 70% cheaper than pure hourly for a deployment you keep running.
-   <mark>Break-even sketch</mark>: the 110-PTU `gpt-5.2` example (from the sizing section in the parent article) costs about 110 × $221 ≈ **$24,000/month** on a 1-year Global reservation. That only makes sense if the same sustained ~360,000 TPM on pay-per-token would cost more — which, at high steady utilization, it typically does.
-   <mark>Not OpenAI-only</mark>: PTU also covers select non-OpenAI models sold by Azure (DeepSeek, Llama) at the same hourly rate, though with higher minimums (for example DeepSeek min 100 PTU). One PTU pool can flex across OpenAI and DeepSeek.
