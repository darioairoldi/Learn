## 🎯 When this appendix applies

This is an appendix to [How GitHub Copilot billing works](00.020-how-ghcp-billing-works.md). The main article covers the current <mark>GitHub AI Credits</mark> model. This page documents the older <mark>premium-request</mark> model that it replaced on June 1, 2026.

You still need it in two cases:

-   <mark>Historical data</mark> — usage before June 1, 2026 is denominated in premium requests, not credits.
-   <mark>Legacy annual plans</mark> — Copilot Pro and Pro+ subscribers who remained on an existing annual plan after the cutover continue to bill this way.

If you're only modeling current spend for Business or Enterprise, you can skip this page.

## 🧮 The premium-request model

Before AI Credits, Copilot metered advanced features in <mark>premium requests</mark>.

| Plan | Included premium requests/month | Overage |
|---|---|---|
| Copilot Pro | 300 | $0.04 USD per extra request |
| Copilot Pro+ | 1,500 | $0.04 USD per extra request |

Behaviors that carry cost-analysis weight:

-   A <mark>premium request</mark> is one user prompt, multiplied by the model's rate.
-   <mark>Counters reset monthly</mark> with no rollover.
-   When the allowance runs out, Copilot falls back to an included model so work continues.
-   Some features consume a fixed number of requests: <mark>Copilot code review = 13 premium requests</mark> per review (from June 1, 2026), <mark>Spark = 4</mark> premium requests per prompt, and <mark>cloud agent = 1</mark> premium request per session (tracked in dedicated SKUs since November 1, 2025).

## ✖️ Model multipliers

The premium-request model expressed model cost differences as a <mark>multiplier</mark>:

-   Each model carried a multiplier based on its complexity and resource use, and your allowance was deducted by that multiplier per prompt.
-   <mark>Auto</mark> model selection routed to a suitable model at a discounted rate — the cheapest default for most prompts.
-   Higher-capability models (frontier reasoning models) consumed more per prompt.

The current AI Credits model expresses the same idea directly through per-model token pricing, so the multiplier concept is legacy-only.

## 🧱 What this means for attribution

For the cost platform, premium-request data maps into the same dimensions as credits, just with a different unit:

| Legacy cost fact | Attribution key | Platform dimension |
|---|---|---|
| Premium requests consumed | User + model | `dim_user`, `dim_model` |
| Fixed-cost features (code review, Spark, cloud agent) | Feature + user | `dim_request_type`, `dim_user` |

When ingesting historical Copilot data, tag each record with its <mark>billing unit</mark> (premium request versus credit) so trend lines don't silently mix the two units across the June 1, 2026 boundary.
