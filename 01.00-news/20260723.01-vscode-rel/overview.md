# VS Code 1.130 — see the canonical summary

This news entry captured the **Visual Studio Code 1.130** release notes (release date **July 22, 2026**). The same release is already documented in full by the canonical Learning Hub summary, so this page links there instead of maintaining a second copy.

> **📄 Canonical article:** [What's new in VS Code 1.130](../20260722-vscode-v1.130-release/01-summary.md)

## What the 1.130 summary covers

- **Agent Host + AHP** — agent sessions run in a dedicated process, shareable across windows, synced via the open Agent Host Protocol.
- **Assisted tool approvals** — the model evaluates each tool call's risk, adding a middle tier between static allow and static deny.
- **Agents window improvements** — file-level diff statistics, a compact multi-file diff, compact quick chats, and worktree support for all harnesses (Copilot, Claude, Codex).
- **Chat** — hover timestamps (`chat.verbose`) and aggregate Copilot Business / Enterprise credit usage in the status menu.
- **Terminal** — clickable file links in Git diffs when `diff.mnemonicPrefix` is enabled.
- **Engineering** — VS Code now compiles with the release version of **TypeScript 7**.

For the full write-up — including the Agent Host process model, the three-tier permission model, and the TypeScript 7 speedups — read the [canonical VS Code 1.130 summary](../20260722-vscode-v1.130-release/01-summary.md).
